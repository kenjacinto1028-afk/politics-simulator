# Model routing

Set by Kenneth (2026-11-18). Follow it in every session.

| Who | Model | Use for |
|---|---|---|
| **Coordinator** (project chat) | **Sonnet** | Planning, status updates, starting threads |
| **Thread, hard work** | **Opus** | Game logic, simulation design, balancing, bug hunting, architecture |
| **Thread, simple jobs** | **Sonnet** | UI text, menus, styling, small tweaks, data entry |

In a thread: Opus does the hard part, then hands simple pieces to a Sonnet helper inside the same thread. Don't open separate chats per model.
